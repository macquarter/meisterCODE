# 크몽 런칭 디자인 에셋 — MEISTERCODE

디자인브리프(`마이스터코드_클로드코드_디자인브리프.md`)의 실행 프롬프트 ①②③을 HTML로 구현하고
Playwright로 PNG를 출력한 결과물입니다. **HTML이 원본, PNG가 납품물**입니다.

## 만들어진 것

| 파일 | 출력 PNG | 크기 | 브리프 대응 |
|---|---|---|---|
| `01-썸네일.html` | `out/01-썸네일-652x488.png` | 652×488 | 실행 프롬프트 ① |
| `02-히어로.html` | `out/02-히어로-860w.png` | 860×731 (@2x 출력) | ② 이미지 A |
| `03-가격표.html` | `out/03-가격표-860w.png` | 860×1013 (@2x 출력) | ② 이미지 B |
| `04-수출기업신뢰.html` | `out/04-수출기업신뢰-860w.png` | 860×768 (@2x 출력) | ③ 이미지 C |

썸네일은 크몽 규격이 고정이라 **1배(652×488)** 로 출력합니다.
상세페이지 이미지는 고해상도 화면 대응을 위해 **2배**로 출력합니다 (크몽이 표시 시 축소).

## 렌더 방법

```bash
bash fonts/fetch.sh      # 최초 1회 — 웹폰트 내려받기
node render.js           # 전체 렌더
node render.js 03        # 가격표만 다시 렌더
```

출력물은 `out/` 에 쌓입니다. 수정은 HTML을 고치고 다시 렌더하면 됩니다.

## 디자인 고정값

`css/base.css` 의 CSS 변수로 잡아두었습니다. 브리프의 "변경 금지" 항목입니다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#0A0E1A` | Navy Ink — 기본 배경 |
| `--navy` | `#1F3D8C` | Meister Navy — 그라디언트 끝 |
| `--blue` | `#3B82F6` | 포인트 |
| `--gold` | `#FFB800` | **가격·특가 강조 전용** |
| `--sky` | `#93C5FD` | 보조 텍스트 |

폰트는 Pretendard(본문·헤드) + Fraunces(영문 포인트).
폰트 바이너리는 용량 때문에 커밋하지 않고 `fonts/fetch.sh` 로 받습니다.

## 아직 안 된 것

- **기존 이미지의 "영구 무료" 문구 수정** — 원본 이미지 파일이 없어 손대지 못했습니다.
  브리프 완료 기준의 마지막 항목입니다. 원본을 주시면 반영합니다.
- 브리프 ③에서 "그대로 재사용"으로 지정한 기존 섹션들(새벽 3시 AI챗봇, 소스코드 인도,
  WordPress 비교, CMS, 5단계 프로세스, 포트폴리오)은 재제작 대상이 아니라 건드리지 않았습니다.

## 검수 메모

썸네일은 검색결과에서 축소 노출되므로 240·300px로 줄여 가독성을 확인했습니다.
300px에서 배지·헤드·가격 모두 판독 가능하고, 180px에서는 배지가 빠듯합니다.

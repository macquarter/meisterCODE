# 크몽 신규 서비스 등록: 마이스터코드 홍보 전담

저장소의 `크몽/AI3D/등록원고.md` 와 `크몽/AI3D/out/652x488/01~09.png` 를
크몽 서비스 등록 화면에 옮겨 넣는다. **저장·검수 제출은 반드시 사용자 확인 후** 누른다.

## 전제 조건 (하나라도 아니면 멈추고 알린다)

- 사용자의 **로그인된 크롬**을 조작할 수 있는 도구가 있다 (Claude in Chrome / 브라우저 확장).
  클라우드 세션의 화면 없는 브라우저로는 하지 않는다. 로그인할 수 없고 크몽 접속도 막혀 있다.
- 비밀번호·쿠키·인증번호를 사용자에게 **요구하지 않는다.** 로그인이 풀려 있으면
  사용자가 직접 로그인하도록 안내하고 기다린다.
- 원고와 이미지가 최신인지 확인한다. 이미지가 없으면 먼저 렌더한다:
  ```bash
  bash 크몽/fonts/fetch.sh
  node 크몽/AI3D/render.js      # → 크몽/AI3D/out/652x488/01~09.png
  ```

## 등록 화면 찾기

이 서비스는 **새로 등록**한다. 기존 서비스(811088 웹 제작)를 덮어쓰지 않는다.
크몽 판매자 메뉴에서 '나의 서비스' → '서비스 등록'(화면에 보이는 라벨 기준)으로 들어간다.
사용자가 기존 서비스를 고쳐 쓰라고 하면, 서비스 번호를 받아 그 편집 화면으로 간다.

## 진행 순서

각 단계가 끝날 때마다 화면을 캡처해 값이 제대로 들어갔는지 확인한 뒤 다음으로 넘어간다.
크몽 화면 구조는 바뀔 수 있으므로, 칸 이름은 **화면에 보이는 라벨**로 찾는다.
'다음' 버튼이 임시저장을 겸하면, 처음 누르기 전에 사용자에게 알리고 승인을 받는다.

1. **카테고리**: 원고 2절. 마케팅 아래 SNS·채널 운영 대행 / 종합 마케팅 계열 중
   화면에 보이는 후보를 사용자에게 보여주고 고르게 한다. 영상 제작 카테고리는 고르지 않는다.
2. **제목**: 원고 1절 추천안. 글자 수 초과 표시가 뜨면 짧은 버전으로 바꾼다.
3. **가격(패키지 3개)**: 원고 5절 표대로 패키지명·가격·작업일·수정 횟수·설명을 넣는다.
   - 할인 전 가격 칸은 **비워 둔다.**
   - 수정 횟수 선택지의 최대값이 원고보다 작으면 최대값을 고르고 사용자에게 보고한다.
   - 카테고리 전용 칸(채널 수·포스팅 수 등)이 있으면 원고 숫자(5개 채널, 월 20·60·100건)로 채우고,
     원고로 채울 수 없는 칸은 비워 두고 사용자에게 묻는다.
4. **서비스 설명**: 원고 4절 박스 전체. 줄바꿈과 ※ 각주가 유지됐는지 확인한다.
5. **이미지**: `01.png → 09.png` 순서로 올린다. 01번이 대표 이미지.
   브라우저 도구로 로컬 파일을 첨부할 수 없으면, 이 단계만 사용자에게 맡긴다:
   "이미지 칸에 `크몽/AI3D/out/652x488/` 의 01~09.png를 순서대로 올려주세요"라고 안내하고,
   끝나면 순서가 원고 3절 표와 같은지 확인한다.
6. **수정 및 재진행 안내 / 의뢰인 준비사항 / FAQ / 검색 키워드**: 원고 6~9절.
7. **금지 표현 최종 점검**: 화면 전체 텍스트에서 아래가 없는지 확인한다.
   - "엔진", "학습", "폐루프", "알아서 자동으로" (노력 없이 하는 느낌을 주는 표현)
   - "보장", "무조건", "1위", "가장 많이 선택" (단, FAQ의 "보장하지 않습니다"는 그대로 둔다)
   - "매일 발행"을 기본 제공처럼 쓴 문장 (매일 발행은 상담 후 견적)
   - 외부 URL, 전화번호, 이메일, 카카오톡 ID, SNS 계정 핸들 (크몽 정책 위반)
8. **멈춤**: 저장/검수 제출 버튼은 누르지 않는다. 바뀐 항목 요약과 캡처를 사용자에게 보여주고
   "제출할까요?"라고 묻는다. 사용자가 승인하면 그때 누른다.
9. 제출 후 크몽 검수(심사) 상태 문구가 뜨면 그대로 전달한다. 반려되면 사유를 받아
   원고를 고친 뒤 이 스킬을 다시 돌린다. 시세 비교 문구가 반려 사유면 원고 체크리스트 마지막 항목대로 고친다.

## 하지 말 것

- 사용자 승인 없이 저장·제출·삭제하지 않는다.
- 기존 서비스(811088)를 이 원고로 덮어쓰지 않는다.
- 원고에 없는 문구를 지어내서 채우지 않는다. 칸이 원고와 맞지 않으면 묻는다.
- 원고의 "올리기 전 체크리스트" 절은 사용자용이다. 크몽 화면에 넣지 않는다.
- 크몽 화면이 예상과 달라 같은 동작이 두 번 실패하면, 반복하지 말고 화면 캡처와 함께 보고한다.

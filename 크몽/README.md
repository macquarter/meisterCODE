# 크몽 런칭 디자인 에셋 — MEISTERCODE

디자인브리프의 실행 프롬프트 ①②③을 HTML로 구현하고 Playwright로 PNG를 출력합니다.
**HTML이 원본, PNG가 납품물**입니다.

## 톤앤매너 기준

드라이브 톤앤매너 폴더(기존 상세페이지 `1~13.jpg`, `썸네일.png`)를 분석해 규칙을 뽑았습니다.
**PPT처럼 보이지 않게 하는 건 결국 아래 다섯 가지를 지키는 것**입니다.

| 원칙 | 왜 |
|---|---|
| **좌측 정렬** | 가운데 정렬 히어로는 즉시 슬라이드로 읽힌다 |
| **블루 단일 액센트, 반전 단어만** | 색이 두 개 이상이면 강조가 무너진다 (레퍼런스 전 이미지에 골드 0회) |
| **밴드별 배경 반전** (다크 ↔ 라이트 ↔ 연블루) | 세로로 긴 상세페이지에 리듬을 만든다 |
| **균등 카드 그리드 금지** | 3등분 카드 나열이 PPT의 가장 큰 신호 |
| **이모지 금지** | 🌏🏭📋 는 템플릿 티가 난다. SVG 라인 아이콘 또는 실사 |

### ⚠️ 브리프와 충돌하는 지점

브리프는 *"포인트 Blue + Gold, 가격·특가 강조는 Gold"* 를 **변경 금지**로 지정했지만,
톤앤매너 폴더에는 **골드가 한 번도 등장하지 않고 가격(30만원)도 블루**입니다.
톤앤매너를 우선해 **골드를 제거**했습니다. 되돌리려면 `css/base.css` 의 `--blue` 를 쓰는
가격 관련 클래스만 골드로 바꾸면 됩니다.

## 만들어진 것

| 파일 | 출력 PNG | 크기 | 브리프 대응 |
|---|---|---|---|
| `01-썸네일.html` | `out/01-썸네일-652x488.png` | 652×488 | 실행 프롬프트 ① |
| `02-히어로.html` | `out/02-히어로-860w.png` | 860×1097 (@2x) | ② 이미지 A |
| `03-가격표.html` | `out/03-가격표-860w.png` | 860×1626 (@2x) | ② 이미지 B |
| `04-수출기업신뢰.html` | `out/04-수출기업신뢰-860w.png` | 860×1457 (@2x) | ③ 이미지 C |

썸네일은 크몽 규격이 고정이라 **1배(652×488)**, 상세페이지 이미지는 고해상도 대응을 위해 **2배**로 출력합니다.

## 렌더 방법

```bash
bash fonts/fetch.sh      # 최초 1회 — 웹폰트 내려받기
node render.js           # 전체 렌더
node render.js 03        # 가격표만 다시 렌더
```

## 디자인 토큰 (`css/base.css`)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--black` | `#000000` | 다크 밴드 기본 |
| `--blue` | `#2E7BF6` | **유일한 액센트** |
| `--blue-lit` | `#5AA0FF` | 다크 위 강조 텍스트 |
| `--paper` | `#F2F4F8` | 라이트 밴드 |
| `--gray` / `--gray-d` | `#8B96A8` / `#5A6577` | 다크 위 / 라이트 위 본문 |

폰트는 Pretendard. 바이너리는 용량 때문에 커밋하지 않고 `fonts/fetch.sh` 로 받습니다.

## 아직 안 된 것

- **실사 사진·3D 오브젝트 없음** — 레퍼런스는 인물 실사(사장님), 건물 비교 실사,
  3D 렌더(서버랙·방패·클라우드)를 적극 씁니다. 현재 에셋은 타이포와 SVG만으로 구성돼 있어
  **히어로 우측에 여백이 남습니다.** 이미지 소스를 주시거나 생성 승인을 주시면 채웁니다.
- **기존 이미지의 "영구 무료" 문구 수정** — 원본 파일이 없어 미반영.
  참고로 기존 `7.jpg` 비교표의 호스팅비 항목에도 "영구 무료"가 들어가 있어 함께 손봐야 합니다.

## 검수 메모

썸네일은 검색결과에서 축소 노출되므로 180·240·300px로 줄여 가독성을 확인했습니다.
300px에서 배지·헤드·가격 모두 판독 가능합니다.

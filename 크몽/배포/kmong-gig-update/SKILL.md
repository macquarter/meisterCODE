## 진행 순서

각 단계가 끝날 때마다 화면을 캡처해 값이 제대로 들어갔는지 확인한 뒤 다음으로 넘어간다.
크몽 화면 구조는 바뀔 수 있으므로, 칸 이름은 **화면에 보이는 라벨**로 찾는다.

1. **현재 상태 백업**: 바꾸기 전에 기존 제목·설명·가격·FAQ를 읽어 사용자에게
   텍스트로 보여주고 보관을 권한다. 되돌릴 수 있어야 한다.
2. **제목**: 원고 1절의 추천안. 글자 수 초과 표시가 뜨면 짧은 버전으로 바꾼다.
3. **이미지**: 기존 이미지를 지우고 `01.png → 09.png` 순서로 올린다.
   브라우저 도구로 로컬 파일을 첨부할 수 없으면, 이 단계만 사용자에게 맡긴다:
   "이미지 칸에 01~09.png를 순서대로 올려주세요"라고 안내하고, 끝나면 순서를 확인한다.
4. **서비스 설명**: 원고 3절 박스 전체. 줄바꿈이 유지됐는지 확인한다.
5. **가격(패키지 3개)**: 원고 4절 표대로 패키지명·가격·작업일·수정 횟수·설명을 넣는다.
   할인 전 가격 칸이 있을 때만 45만/89만/150만을 넣는다.
   화면에 없는 항목(예: 월 구독 옵션)은 억지로 넣지 말고 사용자에게 보고한다.
6. **수정 및 재진행 안내 / 의뢰인 준비사항 / FAQ / 검색 키워드**: 원고 5~8절.
7. **금지 표현 최종 점검**: 화면 전체 텍스트에서 아래가 없는지 확인한다.
   - "영구 무료", "평생 무료", "무제한 수정", "24시간 즉시 대응"
   - "수출바우처", "지원금 안내"
   - 외부 URL, 전화번호, 이메일, 카카오톡 ID (크몽 정책 위반)
8. **멈춤**: 저장/제출 버튼은 누르지 않는다. 바뀐 항목 요약과 캡처를 사용자에게 보여주고
   "저장할까요?"라고 묻는다. 사용자가 승인하면 그때 누른다.
9. 저장 후 크몽 검수(심사) 상태 문구가 뜨면 그대로 전달한다. 반려되면 사유를 전달한다.

## 하지 말 것

- 사용자 승인 없이 저장·제출·삭제하지 않는다.
- 원고에 없는 문구를 지어내서 채우지 않는다. 칸이 원고와 맞지 않으면 묻는다.
- 원고의 "올리기 전 체크리스트" 절은 사용자용이다. 크몽 화면에 넣지 않는다.
- 크몽 화면이 예상과 달라 같은 동작이 두 번 실패하면, 반복하지 말고 화면 캡처와 함께 보고한다.

# 출시 체크리스트

현재 판: **1.0.0-rc.1** (출시 후보). 아래 ✅ 는 코드로 끝낸 것, ⬜ 는 사람이 정하거나 해야 하는 것.

## 1. 반드시 먼저 정할 것

| | 항목 | 왜 | 할 일 |
|---|---|---|---|
| ⬜ | **게임 이름** | `AFTERMATH` 는 원작(TwoHeads Games, 2010, iOS)의 이름이다. 같은 장르·같은 이름으로 상업 출시하면 상표 분쟁 소지가 크다 | 새 이름을 정한다 → `js/settings.js` 의 `APP`, `index.html` 제목·메타, `manifest.webmanifest`, `store/listing.md`, 타이틀 로고만 바꾸면 된다 |
| ⬜ | **원작 표기** | 지금 정보 화면에 "영감: AFTERMATH (TwoHeads Games)" 가 있다. 오마주 표기는 괜찮지만, 이름을 바꾼 뒤에는 원작과 혼동되지 않게 | 이름 확정 후 문구 확인 |
| ⬜ | **실제 랜드마크** | 광화문 · 도쿄 타워 · 센소지 · 왓 아룬 등을 양식화해 그렸다. 일부 건축물(예: 도쿄 타워)은 운영사가 상업적 이미지 사용을 관리한다 | 출시 지역 기준으로 확인하거나, 이름을 일반화(예: '전파탑')하는 선택지가 있다 — 코드에서 이름만 바꾸면 된다 |
| ⬜ | **가격 · 수익 모델** | 무료/유료/광고. 광고나 결제를 넣으면 개인정보 처리방침과 스토어 신고 내용이 바뀐다 | 결정 |
| ⬜ | **연락처** | 스토어와 `privacy.html` 에 필요 | `privacy.html` 의 "문의" 칸 채우기 |

## 2. 어디에 내나

| 경로 | 준비 상태 | 남은 일 |
|---|---|---|
| **웹 (GitHub Pages)** | ✅ 정적 파일만, 빌드 없음. `docs/aftermath/` 가 그대로 배포된다 | 저장소 Pages 설정 확인, 도메인(선택) |
| **itch.io (웹 게임)** | ✅ `docs/aftermath/` 폴더를 zip 으로 올리면 된다(index.html 이 맨 위) | 페이지 문안·스크린샷은 `store/` 사용 |
| **Google Play** | ✅ PWA(매니페스트 · 아이콘 · 오프라인) 준비됨 | Bubblewrap/PWABuilder 로 TWA 패키지 생성 → Play Console 등록(개발자 계정 $25), Digital Asset Links 파일을 사이트에 올림 |
| **App Store (iOS)** | ⬜ 웹 앱만으로는 심사 통과가 어렵다(4.2 최소 기능) | Capacitor 등으로 네이티브 래핑 + Apple 개발자 계정($99/년) |
| **Steam / PC** | ⬜ | Electron/NW.js 래핑, Steamworks(앱 등록비) — 업적·클라우드 저장을 붙이면 좋다 |

## 3. 코드로 끝낸 것

- ✅ 8챕터 + 서바이벌(3도시), 연출가, 특수 감염체, 보스
- ✅ 쉬운 조작(떠 있는 스틱 · 자동 조준), 키 설정, 게임패드, 터치 버튼 크기, 진동
- ✅ 난이도 3단계 + 두 번 죽으면 쉬운 난이도 권유, 사망 원인별 요령
- ✅ 프레임: 픽셀 예산 · 자동 화질, 큰 화면 확대
- ✅ 오류에 버티는 게임 루프, 오류 기록(기기 안)
- ✅ 설치형(PWA) · 오프라인
- ✅ 한국어 · 영어
- ✅ 정보 화면 · 개인정보 처리방침 · 진행 기록 지우기
- ✅ 스토어 스크린샷 · 대표 이미지 · 등록 문안(한·영)
- ✅ 회귀 시험 22종

## 4. 출시 전에 사람이 해 볼 것

- ⬜ 실제 휴대폰(안드로이드 · 아이폰)에서 한 챕터씩 — 터치감, 진동, 발열, 배터리
- ⬜ 다른 사람 3~5명에게 1~3장을 시켜 보고 어디서 막히는지 보기(설명 없이)

## 판 올리기

`js/settings.js` 의 `APP.version` 과 `sw.js` 의 `VERSION` 을 **같이** 올린다 — 서비스 워커가 예전 캐시를 지우고 새 파일을 받는다.

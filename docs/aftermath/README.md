# AFTERMATH — 잔존

브라우저에서 바로 돌아가는 **톱다운 좀비 서바이벌 슈터**.
2010년 TwoHeads Games의 iOS 게임 *Aftermath* 트레일러
([YouTube](https://youtu.be/VuD_wL-vowc))의 게임 구조와 분위기를 참고해 새로 구현했다.
원작 에셋은 일절 사용하지 않았고, 그래픽·사운드는 전부 코드로 생성한다.

## 원작에서 가져온 설계

| 원작 요소 | 구현 |
|---|---|
| 어둡고 비 오는 도시, 손전등 불빛만 보임 | 화면 전체를 덮는 어둠 마스크에 손전등 원뿔 모양의 구멍을 뚫는다. 원뿔은 레이캐스트로 벽에 가려진다 |
| 좌 = 이동 / 우 = 좌우 회전 | 모바일 기본은 **회전 스틱**(민 만큼 손전등이 돈다). 데스크톱은 WASD + 마우스 조준 |
| 사격 버튼 없음 — 불빛을 비추면 저절로 쏜다 | 원뿔 안·사거리 안·시야가 트인 적을 **겨눠** 자동 발사. 터치에선 사격 버튼을 숨긴다 |
| 바닥의 발광 아이콘으로 무기 습득 | 권총(무한) → SMG → 샷건(8발 산탄) → 소총(관통) |
| 무기 고르기 화면 (게임이 멈추고 뒤가 흐려짐) | 터치 `무기` 버튼 / `Tab` — 네 무기와 탄약, 현재 무기는 붉게 |
| 높은 곳에서 내려다보는 3D 도시 | 건물 지붕을 시점 기준으로 밀어내 벽면이 드러나는 의사 3D |
| 미니맵 · 전체 지도 (1.1 업데이트) | 원형 미니맵 + 브리핑 화면의 구역 지도 |
| 밝기 조절 (1.1 업데이트) | 설정의 밝기 슬라이더 |
| 서바이벌은 스토리를 끝내야 열림 | 8챕터 완수 시 개방 |
| 좁은 골목·컨테이너·차량·횡단보도 | 시드 기반 도시 생성기가 블록·뒷골목·안뜰·붕괴지와 구조물을 배치 |
| 폭발물로 무리를 정리 | 수류탄(튕김 + 시야 판정 범위 피해 + 백색 섬광) |
| 암흑 속에서 빛나는 붉은 눈 | 타이틀 배경과 게임 중 미탐지 구역의 유일한 단서 |
| 천둥 · 심장박동 | 번개가 순간적으로 맵 전체를 드러내고, 적이 붙으면 심장박동이 빨라진다 |

## 원작 분석 — 스스로 확인한 것

트레일러 하나로 시작했지만 "원작처럼"을 추측으로 채우지 않으려고 1차 자료를 직접 확인했다.

**리뷰 (2010–2011)**
- TouchArcade — 왼쪽은 이동, 오른쪽은 **좌우 회전**. "손전등으로 가리키면 사격은 자동".
  비 내리는 어둠 속에서 번개가 무리를 드러낸다. 막다른 골목·차량·건물이 있는 큰 도시에서 길을 잃는다.
- PocketGamer — "비틀대는 취객이 아니라 **Left 4 Dead 의 달리는 무리**". 목표는 안전지점 도달 또는
  정해진 시간 생존. 진행할수록 더 위험한 변종. 짧은 질주. 서바이벌은 끝까지 가야 열린다.
- TouchArcade 1.1 업데이트 — 밝기 조절, 새 전체 지도와 화면 미니맵, 화면 전체로 돌리는 선택 조작.

**플레이 영상 프레임 측정** (원작 iPhone 플레이 영상 4분, 3초 간격 80프레임)

| 항목 | 원작 | 이전 구현 | 지금 |
|---|---|---|---|
| 평균 밝기 (0‒255) | ≈ 22 | 8 | ≈ 16 |
| 손전등 빛 색 (밝은 픽셀 평균 RGB) | 145, 138, 138 — 거의 흰빛 | 노란빛 | 흰빛 |
| 번개 순간 평균 밝기 | ≈ 120 | ≈ 30 | ≈ 110 |
| 어둠 속 도시 | 도로·건물 윤곽이 희미하게 보임 | 거의 완전한 암흑 | 희미하게 보임 |

영상 장면 분석에서 확인한 것: 무기는 권총·SMG·샷건·소총 네 종류이고 고르는 화면에서 탄약이 함께 보인다.
버려진 차량·주유소·트럭이 늘어선 거리, 높은 시점의 3D 카메라. 사망 화면은 처치·명중률·받은 피해·총점.
터치 배치는 왼쪽 아래 이동 스틱, 오른쪽 회전 스틱, 오른쪽 아래 작은 버튼 몇 개, 위쪽 가장자리의 게이지.

원작의 그래픽·사운드·문구는 쓰지 않는다. 구조와 감각만 옮긴다.

## 구성

```
docs/aftermath/
├── index.html          화면 구조 · HUD · 메뉴
├── css/game.css        UI 스타일 (터치 레이아웃 포함)
└── js/
    ├── settings.js     음량 · 난이도 · 접근성 설정 (localStorage)
    ├── levels.js       8개 챕터 + 서바이벌 데이터
    ├── audio.js        WebAudio 절차적 사운드 (오디오 파일 없음)
    ├── world.js        도시 생성 · 충돌 · DDA 레이캐스트 · 가시 폴리곤
    ├── entities.js     플레이어 · 감염체 6종(보스 포함) · 총알 · 수류탄 · 산 · 보급품
    └── game.js         게임 루프 · 렌더 · 조명 합성 · 입력 · UI · 전적 평가
```

의존성 없음. 정적 파일만으로 동작한다.

## 캠페인

8개 챕터에 네 종류의 목표가 섞여 있다.

- **escape** — 집결지까지 이동
- **collect** — 보급 상자/연료통/배터리를 모은 뒤 이동
- **survive** — 제한 시간 생존 후 개방된 차단문으로 이동
- **purge** — 지정 수량 소탕 후 이동

챕터 클리어 시 다음 챕터가 열리고 `localStorage`에 진행도가 저장된다.
**서바이벌**은 시간이 갈수록 웨이브 밀도와 러너·브루트 비율이 올라가는 무한 모드로,
최고 생존 시간이 기록된다. 원작처럼 **8챕터를 모두 끝내야 열린다**(이미 서바이벌 기록이 있는 저장은 그대로 열어 둔다).

브리핑 화면에는 이번 구역의 **전체 지도**(진입점·집결지 표시)가, 게임 중에는 **원형 미니맵**이 뜬다.

### 무기

| 무기 | 탄창 | 특징 |
|---|---|---|
| 권총 | 12 | 탄 무한 |
| SMG | 30 | 연사 |
| 샷건 | 6 | 8발 산탄 |
| 소총 | 5 | 한 발 92 피해, 줄 선 감염체를 셋까지 꿰뚫는다(꿰뚫을 때마다 힘이 빠진다). 4챕터에서 처음 줍는다 |

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| 마우스 | 손전등 방향 · 조준 |
| 클릭 / `Space` | 사격 (불빛 안의 적은 자동 사격) |
| `1` `2` `3` `4` / `Q` | 무기 전환 |
| `Tab` | 무기 고르기 (고르는 동안 시간이 멈춘다) |
| `R` | 재장전 (약실이 비면 자동으로 걸린다) |
| `E` / 우클릭 | 근접 밀치기 |
| `G` | 수류탄 |
| `F` | 손전등 on/off (배터리 절약) |
| `Shift` | 전력 질주 (기력 소모) |
| `Esc` | 일시정지 |

모바일은 원작처럼 왼쪽 스틱으로 걷고 **오른쪽 스틱을 좌우로 밀어 손전등을 돌린다**(최대 3.4 rad/s, 민 만큼 빠르게).
사격 버튼은 없다 — 불빛에 들어온 적을 저절로 쏜다(설정에서 자동 사격을 끄면 버튼이 나타난다).
설정의 **터치 조준**에서 원작 1.1의 *화면 드래그*(오른쪽 화면 어디든 좌우로 끌어 돌리기)나 *방향 스틱*(민 방향을 곧바로 봄)으로 바꿀 수 있다.
버튼은 수류탄·무기(고르기 화면)·장전·밀치기·질주·손전등. 가로 화면(원작의 방향)에서는 버튼을 전부 아래쪽 띠로 모으고
게이지는 왼쪽 위, 탄약은 오른쪽 위에 둔다.
두 엄지가 이미 스틱 위에 있으므로 질주는 누르고 있는 버튼이 아니라 **걸쇠**다 — 한 번 누르면
계속 달리고, 숨이 차거나 0.6초 넘게 멈추면 스스로 풀린다(멈춰 있다 다시 움직일 때 의도치 않게
질주해 소음을 내지 않도록). 숨이 찬 동안에는 버튼이 흐려지고 눌러도 걸리지 않는다.

## 감염체

| 종류 | 체력 | 속도 | 성격 |
|---|---|---|---|
| 걷는 것 (walker) | 62 | 47 → 96 | 배회할 땐 느릿하지만, 알아채면 1.2초에 걸쳐 전력으로 달려든다 |
| 달리는 것 (runner) | 38 | 132 | 약한 대신 빠르게 붙는다 |
| 거대한 것 (brute) | 300 | 41 | 밀치기도 거의 안 먹히는 체력 덩어리 |
| 기어다니는 것 (crawler) | 30 | 124 | 웅크렸다 튀기를 반복해 거리를 재기 어렵다. 작고 납작해 눈에 잘 안 띈다 |
| 뱉는 것 (spitter) | 74 | 46 | 215px 거리를 유지하며 산을 뱉는다. 물러서는 것만으로는 안전하지 않다 |
| 그것 (behemoth) | 1500 | 40 | 마지막 챕터의 단 한 마리. 포효로 무리를 깨우고 기어다니는 것을 부르며, 직선으로 돌진한다 |

서바이벌에서는 120초에 그것이 처음 내려오고, 쓰러뜨리면 150초 뒤 다음 개체가 온다.
타이머는 **실제로 내려보냈을 때만** 다음으로 넘어간다 — 자리를 못 찾았다고 시간을
흘려보내면 웨이브가 통째로 사라진다.

**그것**은 총알에도 밀치기에도 경직되지 않는다. 다만 돌진 전 0.85초 동안 제자리에서
몸을 부풀리고 진행 방향에 붉은 예고선이 뜨므로, 그때 비키면 된다. 벽에 박으면
1.1초 비틀거리는데 — 이것이 유일하게 안정적인 반격 창구다.

산 웅덩이는 4.5초간 남아 밟고 있으면 계속 닳는다. 겹친 웅덩이는 더하지 않고
**가장 진한 쪽만** 적용한다 — 더하면 두 겹에 들어선 순간 즉사해 버린다.
어둠 속에서 초록으로 빛나므로 들어서기 전에 알아볼 수 있다.

## 설정 · 난이도

타이틀과 일시정지 화면의 **설정**에서 바꾸며 `localStorage` 에 저장된다.

| 항목 | 내용 |
|---|---|
| 음량 | 0‒100. WebAudio 마스터 게인에 바로 반영된다 |
| 밝기 | 0‒100. 밤의 어둠 농도 (기본 50 = 원작 측정값 근처) |
| 터치 조준 | 회전 스틱(원작) · 화면 드래그(원작 1.1) · 방향 스틱 |
| 난이도 | 생존자 · 잔존(기준) · 절멸 |
| 자동 사격 | 불빛 안의 적을 자동으로 쏠지 |
| 화면 흔들림 | 반동·폭발의 카메라 흔들림 |
| 섬광 효과 | 피격 플래시와 번개의 세기 |
| 도움말 | 조작·적을 처음 마주칠 때 한 줄 설명. 본 것은 다시 뜨지 않고, "처음부터 다시 보기"로 되돌린다 |

난이도는 좀비 체력·피해·스폰 속도·초기 수·보급품 수·배터리 소모·점수 배수를 함께
움직인다. 적용 시점은 **다음에 시작하는 챕터**이며, 전적에는 진입 당시의 난이도가 남는다.

| | 생존자 | 잔존 | 절멸 |
|---|---|---|---|
| 감염체 체력 | ×0.78 | ×1 | ×1.32 |
| 접촉 피해 | ×0.68 | ×1 | ×1.45 |
| 스폰 속도 | ×0.78 | ×1 | ×1.34 |
| 보급품 | ×1.35 | ×1 | ×0.68 |
| 배터리 소모 | ×0.8 | ×1 | ×1.25 |
| 점수 | ×0.8 | ×1 | ×1.35 |

## 전적 평가

클리어/사망 후 S‒D 등급이 붙는다. 100점 만점으로

- 명중률 34점 (75%에서 만점)
- 받은 피해 32점 (192 이상이면 0점)
- 처치 20점 (40기에서 만점)
- 속도 14점 (시간이 목표인 모드는 버틴 시간으로 환산)

를 더한 뒤 난이도 배수를 곱하고, 사망하면 ×0.45 한다.
S 88 · A 73 · B 57 · C 38 · 그 아래 D.
챕터별 최고 평가는 저장되어 챕터 선택 화면에 등급과 점수로 남는다.

## 실행

```bash
python3 -m http.server 8080 --directory docs
# http://localhost:8080/aftermath/
```

GitHub Pages(`docs/` 발행)에서는 `/aftermath/` 경로로 접근한다.

실제 배포 형태(HTTP 서빙)에서도 확인했다 — 자원 8개 전부 200,
`localStorage` 의 설정·진행도·챕터 평가가 새로고침 후 복원되고,
타이틀 → 챕터 선택 → 브리핑 → 진입 → 키 입력 이동까지 동작하며,
WebAudio 합성과 60 FPS, 콘솔 오류 0건. `file://` 과 동작 차이가 없다.

## 구현 메모

- **조명**: 오프스크린 캔버스를 검게 채우고 `destination-out`으로 손전등 원뿔을 지운다.
  원뿔은 폭이 다른 세 겹(±32°/±22°/±12°)을 겹쳐 가장자리를 부드럽게 만든다.
  그 위에 `lighter` 합성으로 흰 발광을 더한다. 막의 기본 농도는 0.74(밝기 50)로,
  원작 영상처럼 불빛 밖에서도 도로·건물 윤곽이 희미하게 남는다. 불빛 밖 감염체는
  실루엣만(불투명도 0.16) 남기고, 손전등·근접·번개가 형체를 드러낸다.
- **의사 3D 건물**: 지붕을 시점(화면 속 플레이어 자리) 기준으로 1.15배 확대한 좌표계에 그리면,
  이웃 타일의 지붕이 어긋나지 않으면서 시점 쪽을 향한 벽면만 드러난다. 벽면은 방향별로
  한 경로에 모아 한 번에 칠한다(층 구분선 포함). 손전등이 벽에 막힌 끝점은 지붕선까지
  들어 올려 빛이 벽면을 타고 오른다. 최대 부하에서도 58fps.
- **잔해**: 무너진 모서리의 잔해 칸은 통과할 수 없는데 그동안 그려지지 않아 보이지 않는 벽이었다.
  이제 콘크리트 조각으로 그린다.
- **자동 사격 조준**: 불빛 안(데스크톱 ±0.30 rad, 터치 ±0.42 rad)의 가장 가까운 표적을 향해 쏜다 —
  회전 스틱은 마우스만큼 정밀하지 않으므로 터치 쪽을 넓혔다.
- **관통**: 소총탄은 맞힌 몸을 기억해 같은 개체를 두 번 맞히지 않고, 명중률은 탄 하나당 한 번만 센다.
- **가시성**: 원뿔 폴리곤은 매 프레임 80/56/40개의 DDA 레이캐스트로 계산해 벽 뒤를 가린다.
- **맵 보증**: 도시 생성 후 이중 BFS로 도로망의 지름을 구해 양 끝을 시작점과 탈출점으로 삼는다.
  탈출점은 정의상 도달 가능하므로 클리어 불가능한 맵이 나오지 않는다.
  구조물이 도로를 지나치게 끊으면 자동으로 걷어내고 다시 계산한다.
- **탄창**: 총마다 약실(권총 12 · SMG 30 · 샷건 6)과 예비탄을 따로 센다.
  약실이 비면 자동으로 장전이 걸리고, 장전 중에는 사격이 막히며 이동 속도가 0.78배로 떨어진다.
  무기를 바꾸면 장전은 취소된다. HUD는 `약실 / 예비탄`과 장전 진행 바를 함께 보여 준다.
- **근접**: 전방 42px·±1.0rad 안의 적을 24 피해로 밀어낸다(0.58초 쿨다운).
  달라붙은 좀비를 떼어내는 용도라 넉백(일반 56px, 브루트 22px)과 경직이 피해보다 중요하다.
- **발소리**: 걸으면 소음 0.1, 질주하면 0.38 이 깔린다. 좀비의 청각 범위는
  `hear × (1 + noise × 1.6)` 이므로 질주 중에는 1.6배 멀리서도 깨어난다.
  기력이 "달릴 수 있는가"를 묻는다면 이쪽은 "달려도 되는가"를 묻는다.
  사격 소음(1.0)을 덮지 않도록 둘 중 큰 값을 쓴다.
- **기력**: 질주는 24/s로 닳고 0.5초 뒤부터 20/s로 찬다. 바닥까지 쓰면 숨이 차서(`winded`)
  45까지 회복할 때까지 다시 달릴 수 없다 — 하한을 0으로 두어야 0 근처에서 질주가 떨리지 않는다.
- **설정**: `js/settings.js` 가 가장 먼저 로드되어 `SETTINGS`/`DIFFICULTY` 를 노출한다.
  저장값이 손상돼 있으면 타입을 확인해 기본값으로 떨어뜨린다.
- **보스 배치**: `pickPoint` 는 범위를 못 맞추면 아무 도달 가능 타일이나 돌려준다.
  그대로 쓰면 보스가 지도 반대편에 떨어지므로 거리를 직접 검산하고, 그래도 없으면
  탈출점에서 가장 가까운 "몸이 들어가는" 타일을 직접 고른다. 챕터 8은 시드가 고정이라
  그것은 매번 같은 자리(탈출점에서 580px)에서 기다린다.
- **도움말**: 조작법 화면을 읽고 들어오지 않아도 되도록, 상황이 처음 생기는 순간에 한 줄을
  띄운다 — 탄창이 1/3 남으면 장전, 적이 달라붙으면 밀치기, 처음 보는 감염체가 불빛에
  들어오면 그 개체 소개. 밀치기·장전·적 소개처럼 지금 알아야 하는 것은 대기열 앞으로 끼운다.
  데스크톱과 터치는 문구가 다르다(키 이름 대신 버튼 이름). 본 기록은 `localStorage`.
- **조준선**: 데스크톱에서는 시스템 커서를 숨기고 캔버스에 직접 그린다. 무기 퍼짐만큼
  벌어지고, 장전 중엔 진행 고리가, 명중하면 흰 X(처치는 붉은 X)가 잠깐 뜬다.
  산탄 8발이 한 프레임에 맞아도 확인음은 한 번만 낸다.
- **카메라**: 세로 터치 화면에서는 플레이어를 화면 40% 높이에 둔다(가로 화면은 버튼이 양옆이라 가운데). 아래 40%를 스틱·버튼이 덮어서,
  정중앙에 두면 지도 끝에서 플레이어가 버튼 밑에 깔렸다. 지도 밖으로는 위아래 UI 띠가
  어차피 가리는 만큼만 넘어간다(데스크톱도 HUD 띠 높이만큼). 목표 나침반은 화면 중앙이
  아니라 실제 플레이어 화면 위치에 매 프레임 붙는다.
- **드론**: 어긋난 두 톱니파를 저역 통과시킨 배경 저음이 긴장도에 따라 열린다.
  AudioParam 자동화는 호출마다 이벤트가 쌓이므로 값이 바뀌었거나 0.25초가 지났을 때만 갱신한다.
- **적 배합**: 레벨의 `mix` 키를 그대로 읽어 정규화하므로 합이 1이 아니어도 되고,
  `ZTYPES` 에 없는 키는 무시한다. 챕터가 올라갈수록 기어다니는 것과 뱉는 것이 섞인다.
- **사운드**: 핑크 노이즈 버퍼와 오실레이터만으로 총성·산탄·폭발·비·천둥·울음소리를 합성한다.

개인정보 처리방침

AFTERMATH — 잔존 · 시행일: 출시일

수집하는 정보

이 게임은 개인정보를 수집하지 않습니다. 회원 가입 · 로그인이 없고, 광고 · 분석(애널리틱스) · 추적 도구를 쓰지 않으며, 게임 중 어떤 정보도 외부 서버로 보내지 않습니다.

기기에 저장하는 것

게임을 이어 하기 위해 다음 항목을 사용자의 기기 안 브라우저 저장소(localStorage)에만 저장합니다. 이 정보는 기기를 떠나지 않습니다.

  • 설정(음량 · 밝기 · 난이도 · 조작 방식 · 키 설정 등)
  • 진행 기록(열린 챕터 · 챕터별 평가 · 서바이벌 최고 기록 · 본 도움말)
  • 최근 오류 기록 최대 20건 — 문제를 제보할 때 사용자가 직접 복사해 보낼 수 있도록 남기며, 자동으로 전송하지 않습니다

게임 안 정보 › 진행 기록 지우기, 또는 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

기기 기능

지원하는 기기에서 피격 · 폭발 시 짧은 진동을 씁니다(설정에서 끌 수 있음). 게임패드를 연결하면 입력만 읽습니다. 카메라 · 마이크 · 위치 · 연락처에는 접근하지 않습니다.

오프라인 실행

설치형(PWA)으로 실행하면 게임 파일을 기기에 캐시해 네트워크 없이도 실행됩니다. 캐시에는 게임 파일만 담깁니다.

아동

개인정보를 수집하지 않으므로 연령과 관계없이 정보를 수집하지 않습니다. 게임에는 좀비 · 폭력 묘사가 있습니다.

변경

이 방침이 바뀌면 이 페이지를 고치고 시행일을 갱신합니다.

문의

문의처는 스토어 등록 정보에 표시된 연락처를 이용해 주세요.

Privacy Policy

AFTERMATH · Effective: release date

What we collect

This game collects no personal data. There is no account or login, no ads, no analytics or tracking, and nothing is sent to any server while you play.

What is stored on your device

To let you continue playing, the game stores the following only in your browser's local storage on your device. It never leaves the device.

  • Settings (volume, brightness, difficulty, control scheme, key bindings, etc.)
  • Progress (unlocked chapters, chapter grades, survival best, hints seen)
  • Up to the 20 most recent error records — kept so you can copy them into a bug report yourself; never sent automatically

Delete them any time via About › Clear progress in the game, or by clearing site data in your browser.

Device features

On supported devices the game uses short vibration on hits and explosions (can be turned off). Connected gamepads are read for input only. The game does not access the camera, microphone, location or contacts.

Offline

When installed as an app (PWA), game files are cached on the device so it runs offline. The cache holds game files only.

Children

As no personal data is collected, none is collected from anyone of any age. The game depicts zombies and violence.

Changes

If this policy changes, this page will be updated with a new effective date.

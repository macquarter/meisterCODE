# LEFT CITY — 제품 진단과 로드맵 (PM 노트)

> 1.0.0-rc.28 기준. "무엇을 더 만들까"보다 "왜 다시 켜는가"를 먼저 묻는다.

## 1. 한 줄 정의
손전등이 닿는 곳까지만 보이는 도시에서, 짧은 한 판(3‒8분)으로 살아 나가는 톱다운 좀비 서바이벌. 모바일 · 데스크톱 브라우저, 설치 없이.

## 2. 지금 상태 진단 (rc.27 까지)
| 축 | 상태 | 판단 |
|---|---|---|
| 핵심 손맛(쏘고 · 밀치고 · 피하기) | 무기 12종, 사방 밀치기, 어둠 조준 페널티, 예고선 | **충분** — 더 넣기보다 다듬을 단계 |
| 콘텐츠 폭 | 12장 × 미션 2개, 서바이벌 15개 도시, 특수 감염체 12종, 도전 5개 | **충분** — 오히려 고를 게 많다 |
| 첫 경험(FTUE) | 프롤로그 → 1-A(쉬운 수집) → 1-B(이야기), 상황별 도움말 | 양호 |
| 다시 할 이유(메타) | 등급 · 과제 · 기록 종이 · 도감뿐 — **판이 끝나면 남는 것이 없었다** | **가장 큰 구멍** |
| 매일 돌아올 이유 | 없음 | **구멍** |
| 측정 | 서버 없음, 로컬 기록만 | 의도된 제약(개인정보) — 플레이테스트로 보완 |

결론: 다음 투자는 콘텐츠가 아니라 **리텐션 루프**다.

## 3. rc.28 에서 한 것 — 리텐션 루프
```
한 판 → 경험치(점수 · 임무 · 도감) → 레벨 업 → 특성 점수 → 다음 판이 조금 쉬워짐 → 한 판 더
           └ 도감 처치 메달(25 · 100 · 500) → 금메달은 그 개체 피해 +6%
매일 → 오늘의 도시(같은 도시 · 같은 지도 · 같은 변수) → 첫 출격 보너스 · 연속 일수
```
- **생존자 레벨 1‒30 · 특성 9종 × 3단계.** 한 단계 6‒15% 로 작게 — 실력을 대신하지 않고 "조금씩 강해지는" 정도.
  단계마다 필요 레벨(1 · 6 · 12)로 뒤쪽 목표를 남긴다. 초기화는 무료(실험을 막지 않는다). 도전 모드는 공정하게 특성 없음.
- **결과 화면이 다음 판의 입구** — 얻은 경험치 내역, 차오르는 막대, 레벨 업, "특성 찍기" 단추.
- **타이틀의 생존자 칩** — 레벨 · 막대 · 쓰지 않은 점수(깜빡임). 메뉴를 늘리지 않고 한 줄로.
- **오늘의 도시** — 날짜로 정해지는 시드. 변수 셋(정전의 밤 · 무리의 날 · 탄약 부족) 중 하나. 첫 출격 +80 XP, 연속 일수.

### 경험치 설계값
| 출처 | 값 |
|---|---|
| 점수 | ×0.2 (도전 ×0.08) |
| 서바이벌 버틴 시간 | 초당 0.8 |
| 미션 완료 | 진입 90 · 본편 150 · 실패해도 25 |
| 도감 새 기록 | 50 |
| 도감 메달 | 동 100 · 은 250 · 금 600 |
| 오늘의 도시 첫 출격 | 80 |

레벨 l → l+1 에 300 + 150(l−1). 본편 한 판(약 400‒650 XP)으로 처음 두세 레벨이 빠르게 오르고, Lv 10 까지 약 20판.

## 4. 지켜볼 지표 (플레이테스트 · 스토어 출시 시)
- D1 / D7 재방문율 — 오늘의 도시 연속 일수 분포로 대리 측정
- 첫 판 완료율(1-A), 1-B 진입률 — FTUE 의 깔때기
- 판당 사망 원인 상위 3 (DEATH_TIP 키) — 난이도 조정 근거
- 레벨 분포 · 특성 선택 분포 — 한 특성에 쏠리면 값 조정
- 도감 완성률 · 금메달 수

## 5. 다음 로드맵 (제안, 우선순위 순)
1. **주간 목표 3개**(예: 덮치는 것 30기 · 오늘의 도시 3회 · 무피해 미션) — 오늘의 도시 위에 얹는 중기 목표.
2. **무기 숙련도 → 부품**(조준경 · 확장 탄창 · 소음기) — 이미 상세화한 무기 그림 · 모형이 바탕.
3. **은신처(거점)** — 구한 생존자 · 자원으로 시설을 늘리고 판 시작 보너스.
4. **기록 공유** — 오늘의 도시 결과 카드 이미지(시드 · 시간 · 처치)를 저장 · 공유. 서버 없이 바이럴 고리.
5. 스토어 출시 시에만: 익명 이벤트 수집(옵트인)으로 위 지표를 실제로 잰다.

## 6. 하지 않을 것
- 확률형 뽑기 · 유료 강화 — 손맛 게임의 신뢰를 깎는다.
- 특성 효과를 크게(20%+) — 레벨이 실력을 대신하면 짧은 판의 긴장이 무너진다.
- 메뉴 버튼 추가 — 새 기능은 기존 화면(타이틀 칩 · 결과 화면 · 도시 선택)에 붙인다.

# 메종 마이스터 백엔드 설치 가이드 (구글 시트 + Apps Script)

구글 시트 하나가 **백오피스**가 됩니다. 서버 비용 0원.

| 하는 일 | 방법 |
|---|---|
| VIP 초대 코드 발급 | "초대코드" 시트에 행 추가 |
| 코드 중지/만료 | 상태를 `중지`로 바꾸거나 만료일 설정 |
| 예약 접수 확인 | "예약" 시트에 자동으로 쌓임 + 이메일 알림 |

## 설치 (약 5분, 최초 1회)

1. **시트 만들기** — [sheets.new](https://sheets.new) 에서 새 스프레드시트 생성 (이름 예: `메종 마이스터 운영`)
2. **스크립트 열기** — 메뉴 `확장 프로그램 → Apps Script`
3. **코드 붙여넣기** — 기본 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 전체를 붙여넣기 → 저장(💾)
4. **초기화 실행** — 상단 함수 선택에서 `setup` 선택 → `실행` 클릭
   - 처음 실행 시 권한 승인 창이 뜹니다: `권한 검토 → 계정 선택 → 고급 → 이동 → 허용`
   - 완료되면 시트에 "초대코드", "예약" 탭이 생깁니다
5. **웹 앱 배포** — 우측 상단 `배포 → 새 배포`
   - 유형 선택(⚙️): **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 중요
   - `배포` → 표시되는 **웹 앱 URL 복사** (`https://script.google.com/macros/s/…/exec`)
6. **사이트에 연결** — 레포의 `docs/js/config.js` 를 열어 복사한 URL을 붙여넣기:
   ```js
   window.MEISTER_CONFIG = {
     API_URL: "https://script.google.com/macros/s/여기에붙여넣기/exec"
   };
   ```
   커밋/푸시하면 GitHub Pages에 자동 반영됩니다.

> `API_URL`이 비어 있는 동안 사이트는 **데모 모드**(공용 코드 `MEISTER`)로 동작합니다.
> URL을 넣는 순간부터 시트의 개별 코드만 통과됩니다.

## 운영 방법

### 초대 코드 발급
"초대코드" 시트에 행을 추가하면 즉시 사용 가능:

| 코드 | 고객명 | 상태 | 만료일 | 사용횟수 | 마지막 사용 |
|---|---|---|---|---|---|
| `KIM-2026-A7` | 김○연 | 활성 | 2026-12-31 | (자동) | (자동) |

- **코드**: 자유 형식 (대소문자 구분 없음)
- **상태**: `활성` 만 통과. `중지` 로 바꾸면 즉시 차단
- **만료일**: 비워두면 무기한. 날짜가 지나면 자동 거부
- **사용횟수/마지막 사용**: 고객이 입장할 때마다 자동 기록 — 누가 실제로 들어왔는지 확인 가능

### 예약 수신
- 예약이 들어오면 "예약" 시트에 한 줄 추가 + **이메일 즉시 발송**
- 알림 받을 주소를 바꾸려면 `Code.gs` 맨 위 `NOTIFY_EMAIL = "원하는@주소"` 수정 후,
  `배포 → 배포 관리 → 수정(✏️) → 새 버전 → 배포`

### 코드를 수정했을 때
Apps Script 코드를 고친 뒤에는 반드시 `배포 → 배포 관리 → 수정 → 새 버전 → 배포` 를 해야 반영됩니다. (URL은 그대로 유지됨)

### rc.42 에서 고친 휴대폰 문제
- **뒤로 단추(안드로이드) · 가장자리 밀기(iOS)** — 판 도중 누르면 앱이 그대로 닫혔다 → 판 중이면 멈춤, 창이 떠 있으면 닫기, 하위 화면이면 앞 화면. 타이틀에서만 앱을 나간다.
- **3D 그리기 문맥 잃음(iOS 가 앱 전환 · 메모리 부족 때 흔히 한다)** — 곧바로 2D 로 떨어지던 것을 기다렸다 복구. 화면에 보이는 채로 6초 지나도 안 돌아오면 그때 2D.
- **iOS 몸짓** — 두 손가락 확대 · 두 번 톡 확대 · 길게 눌러 뜨는 메뉴를 막는다. 가로로 돌릴 때 글자가 커지지 않게.
- **iOS 소리** — 오디오 세션을 '주변음(ambient)'으로: 무음 스위치를 따르고, 듣던 음악을 끊지 않는다.
- **작은 아이폰(SE 1세대 568pt)** — 타이틀의 설정 · 조작 · 정보가 화면 밖이었다 → 짧은 세로 화면 배치.
- **매니페스트** — 방향 `landscape` 고정 → `any`(세로 화면용 배치가 있으므로), `id` · `display_override` 추가.
- **App Store 스크린샷** — 기존 1920×1080 은 Play 만 받는다. iPhone 6.9″(2868×1320)와 iPad 13″(2752×2064)를 한 · 영 7장씩 새로 만들었다(`store/ios-iphone-6.9/`, `store/ios-ipad-13/`, 터치 화면 그대로).

## 2-2. 정식판 결제 연결 (rc.43)

게임은 결제를 직접 하지 않는다. 앱 껍데기(Capacitor · TWA)가 아래 세 함수를 `window.LeftCityStore` 로 넣어 주면 정식판 안내 화면이 그대로 쓴다.

```js
window.LeftCityStore = {
  price:    async () => '₩6,900',          // 스토어가 준 현지 가격 문자열 — 단추에 붙는다
  purchase: async () => true | false,       // 결제 성공이면 true(취소는 false, 오류는 throw)
  restore:  async () => true | false        // 이미 산 사람이면 true
};
```

| | 할 일 |
|---|---|
| ⬜ | **iOS** — Capacitor + StoreKit 플러그인(예: RevenueCat · cordova-plugin-purchase), 비소모성 상품 `full_game`. App Store 규정상 **'구매 복원' 단추가 필수** — 안내 화면에 있다 |
| ⬜ | **Android** — TWA 라면 Digital Goods API + Payment Request 로 Play 결제(Play 는 디지털 상품에 Play 결제 필수), Capacitor 라면 같은 플러그인 |
| ✅ | 무료 범위: 1‒3장(여섯 미션) — 첫 판부터 3장 끝까지 약 25‒40분. 3장 끝 무전과 마무리 글이 방콕으로 매달고, 안내 화면이 그 장면을 이어 보여 준다 |
| ✅ | 진행은 기기 안(localStorage) — 결제 뒤 그대로 4장부터. 웹에서는 결제 대신 스토어 안내 문구 |
| ⬜ | 웹판(GitHub Pages · itch.io)을 어떻게 둘지 — 지금은 웹도 3장까지만. 웹을 전부 무료로 두려면 웹 빌드에서 `Full.open` 을 늘 참으로 |

## 2-3. 방향 메모 (rc.45 — 출시 일정은 아직 정하지 않는다)

- 무료 1부(1‒3장) → 정식판 2‒4부. 부 경계마다 엔딩 카드가 있어 '다음 부'가 결제 동기가 된다
- 정식판 혜택: 4장 이후 전부 + 게임 속도 3x. 체력 이어짐 · 실내 잠입 · 4부 비극 엔딩이 정식판의 '끝까지 하고 싶은' 축
- 웹 데모(설계자용)는 `LC_FULL_BUILD` 로 정식판 상태로 전달

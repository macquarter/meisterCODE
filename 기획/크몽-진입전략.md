# 크몽 진입 전략 — meisterCODE

> 작성 기준: `docs/` 프론트엔드 + `backend/apps-script/` 백엔드 실물 코드 분석
> 상태: 1차 초안 (디자인브리프 미반영 — 파일 전달 후 갱신 예정)

---

## 1. 냉정한 전제 — 정면승부는 지는 싸움이다

크몽 "홈페이지 제작" 카테고리의 현재 상태:

| 항목 | 수치 |
|---|---|
| 등록 서비스 수 | 1,110+ (웹빌더 서브카테고리만) |
| 평균 견적 | 약 80만원 |
| 견적 범위 | 40만 ~ 180만원 |
| 회사소개형 단순 사이트 | 79만원선 |
| 예약·관리자 기능 포함 | 180만원 이상 |

문제는 가격이 아니라 **구조**다. 크몽 랭킹은 리뷰 수·평점·주문성공률·응답률로 결정된다.
신규 판매자는 리뷰 0 → 검색 하위 노출 → 주문 0 → 리뷰 0 의 데드락에 갇힌다.

**"홈페이지 제작" 단일 키워드로 1,110개와 붙으면 우리는 보이지 않는다.**
이기는 방법은 더 싸게 파는 게 아니라, 경쟁자가 구조적으로 못 하는 걸 파는 것이다.

---

## 2. 상위 경쟁자의 구조적 약점 3가지

대부분의 크몽 상위 판매자는 아임웹·윅스·카페24 등 **임대형 빌더** 또는 **워드프레스** 기반이다.
여기서 세 가지 약점이 나온다.

### ① 영구 월 유지비
임대형 빌더는 월 3~5만원이 영구적으로 나간다.
예약·멤버십 기능은 대개 유료 플러그인이거나 상위 요금제다.
**5년이면 유지비가 제작비를 넘는다.** 클라이언트는 계약 시점엔 이걸 계산하지 않는다.

### ② 납품 후 단절
워드프레스나 자체 개발로 만들면 클라이언트가 손을 못 댄다.
텍스트 한 줄 고치려고 개발자에게 연락해야 하고, 그래서 유지보수 계약이 강요된다.
**클라이언트가 가장 싫어하는 지점이고, 크몽 저평점 리뷰의 최대 원인이다.**

### ③ 템플릿 티
40~80만원 구간은 사실상 템플릿 갈아끼우기다.
프리미엄·럭셔리 브랜드가 요구하는 "만듦새"가 안 나온다.

## 3. 우리 자산이 정확히 그 셋을 때린다

`MAISON MEISTER` 코드베이스에 이미 구현되어 있는 것들:

| 경쟁자 약점 | 우리 자산 | 코드 근거 |
|---|---|---|
| 영구 월 유지비 | GitHub Pages 정적 호스팅 + Apps Script 무료 티어 = **월 0원** | `docs/` 배포 구조, `backend/apps-script/Code.gs` |
| 납품 후 단절 | **구글시트가 곧 백오피스.** 클라이언트가 이미 쓸 줄 아는 도구로 운영 | `초대코드`·`예약` 시트, 행 추가만으로 운영 |
| 템플릿 티 | 시네마틱 히어로(켄번즈 슬라이드 + 영상 오버레이 + 스파클 캔버스), 3중 폴백 | `docs/js/main.js`, `.img-fallback` |

### 그리고 결정적인 하나 — 자가설치 백엔드

`Code.gs`는 첫 요청 때 **스스로 스프레드시트를 만들고, 탭·헤더·샘플 데이터까지 구성한다.**
클라이언트가 할 일은 붙여넣기 → 배포 → 권한 허용, 3단계 2분이다.

```
사람이 할 일은 붙여넣기 → 배포 → 권한 허용, 이 세 가지뿐입니다.
```

납품 후 "이거 어떻게 써요?"가 안 나온다는 뜻이다.
**크몽에서 별 5개를 만드는 지점은 디자인이 아니라 바로 여기다.**

### 이미 구현된 운영 기능

- 초대코드: 코드별 **상태(활성/중지) · 만료일 · 사용횟수 · 마지막 사용시각** 자동 추적
- 예약: 시트 자동 적재 + **즉시 이메일 발송**, 메일 실패해도 예약은 보존
- 데모 모드: `API_URL`이 비어 있어도 사이트가 완전히 동작 (영업용 시연에 유리)

## 4. 3단 사다리 전략

### 1단 — 리뷰 부트스트랩 (진입용, 마진 포기)

| | |
|---|---|
| 상품 | 랜딩페이지 1장 + 예약/문의 폼 + 구글시트 자동 적재 + 메일 알림 |
| 가격 | **9만 ~ 15만원** |
| 납기 | 3일 |
| 목적 | **오직 리뷰.** 마진은 0에 가깝게 설계 |
| 실제 원가 | 기존 코드 재사용 — 작업 2~3시간 |

리뷰 10~15개까지만 이 가격으로 운영하고 즉시 인상한다.
**3일 납기를 못 박는 이유:** 크몽 랭킹 지표에 "작업일 준수율"이 들어간다.
짧고 확실하게 지킬 수 있는 납기가 랭킹을 올린다.

### 2단 — 주력 수익 (본진)

| | |
|---|---|
| 상품 | 브랜드 홈페이지 + 예약 시스템 + 구글시트 백오피스 |
| 가격 | 79만 / 149만 / 249만 (3단 패키지) |
| 후킹 문구 | **"월 유지비 0원. 예약은 구글시트로 실시간."** |

이 한 문장이 아임웹 기반 경쟁자 전부를 무력화한다.
상세페이지 상단에 **5년 총소유비용(TCO) 비교표**를 넣는다:

| | 임대형 빌더 | meisterCODE |
|---|---|---|
| 제작비 | 80만 | 149만 |
| 월 유지비 | 4만 × 60개월 = 240만 | **0원** |
| 예약 기능 | 플러그인 별도 | 포함 |
| **5년 총액** | **320만** | **149만** |

### 3단 — 카테고리 창출 (독점 구간)

| | |
|---|---|
| 상품 | 초대코드 프라이빗 살롱 / 멤버십 폐쇄몰 |
| 가격 | 149만 ~ 350만원 |
| 타깃 | VIP 전용 판매, B2B 도매가 노출 차단, 공동구매, 회원제 클래스, 셀럽 프리오더 |

**크몽에 이 키워드로 붙는 경쟁자가 거의 없다.**
검색량은 적지만 의뢰인의 구매 의도가 명확하고 단가가 높다.
그리고 우리는 **이미 만들어 놨다** — `validateCode()` 하나로 코드별 만료·차단·사용추적이 다 된다.

경쟁자가 이걸 하려면 회원 DB, 인증, 관리자 페이지, 서버를 새로 짜야 한다.
우리는 시트 한 장이다.

## 5. 크몽 운영 실무 체크리스트

- [ ] **초기 3개월 CPC 광고 집행** — 리뷰 0 상태에서 노출을 얻는 사실상 유일한 경로
- [ ] **키워드는 조합형으로** — "홈페이지 제작"(레드오션) 대신 `예약 홈페이지 제작`, `멤버십 폐쇄몰 제작`, `구글시트 연동 홈페이지`, `월 유지비 없는 홈페이지`
- [ ] **상세페이지 자체가 포트폴리오** — 홈페이지를 만들어 파는 사람의 상세페이지가 허술하면 그 자체가 실력의 반증이다. 여기에 가장 많은 시간을 쓸 것
- [ ] **응답률 관리** — 랭킹 지표. 알림 즉시 응답 체계 필요
- [ ] ⚠️ **외부 링크·연락처 노출 정책 확인** — 크몽은 외부 거래 유도를 제재한다. 라이브 데모는 이미지/영상 캡처로 상세페이지에 넣고, 실제 URL은 크몽 메시지로 전달하는 것이 안전. **판매 이용약관 원문 확인 필요**

## 6. 지금 데모의 구멍 — 포트폴리오로 쓰기 전에 메울 것

`MAISON MEISTER`를 크몽 대표 포트폴리오로 내세우려면 아래가 먼저 해결돼야 한다.

| 구멍 | 현재 상태 | 왜 문제인가 |
|---|---|---|
| **모바일 대응이 얇음** | `style.css`에 미디어쿼리가 **960px 하나뿐** | 크몽 의뢰인은 대부분 모바일로 포트폴리오를 본다. 여기서 깨지면 끝 |
| **라이브 데모 없음** | `config.js`의 `API_URL: ""` — 데모 모드 | 예약이 실제로 시트에 꽂히는 걸 보여줘야 설득이 산다 |
| **외부 스톡 이미지 의존** | Unsplash 외부 링크 22곳 | 스톡 티가 나고, 링크가 죽으면 포트폴리오가 죽는다 |
| **볼륨 부족** | 페이지 3장 (index / salon / product) | 149만원짜리 납품 규모로 보이지 않는다 |

**우선순위:** 모바일 → 라이브 데모 연결 → 이미지 교체 → 페이지 증설

# 메종 마이스터 백엔드 — 설치는 클릭 몇 번이면 끝

구글 시트 하나가 **백오피스**가 됩니다. 서버 비용 0원.
시트 생성·탭 구성은 스크립트가 **전부 자동**으로 합니다 — 사람은 아래 3단계만.

| 하는 일 | 방법 |
|---|---|
| VIP 초대 코드 발급 | "초대코드" 시트에 행 추가 |
| 코드 중지/만료 | 상태를 `중지`로 바꾸거나 만료일 설정 |
| 예약 접수 확인 | "예약" 시트에 자동으로 쌓임 + 이메일 알림 |

## 설치 (3단계, 약 2분)

1. **붙여넣기** — [script.new](https://script.new) 접속 → 기본 내용 지우고 이 폴더의 `Code.gs` 전체 붙여넣기 → 저장(💾)
2. **배포** — 우측 상단 `배포 → 새 배포` → 유형(⚙️): **웹 앱** → 실행 계정: **나** → 액세스 권한: **모든 사용자** → `배포`
   - 권한 창이 뜨면: `권한 검토 → 계정 선택 → 고급 → 이동 → 허용`
3. **URL 전달** — 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서
   - Claude에게 채팅으로 붙여넣어 주시면 사이트 연결(config.js 커밋)까지 마무리해 드립니다
   - (직접 하시려면 `docs/js/config.js`의 `API_URL`에 붙여넣고 커밋)

> 배포된 URL을 브라우저로 한 번 열어보세요 — `{"ok":true, "sheet":"…"}` 응답과 함께
> 드라이브에 **"메종 마이스터 운영"** 시트가 자동 생성됩니다. 그 주소가 백오피스입니다.

> `API_URL`이 비어 있는 동안 사이트는 **데모 모드**(공용 코드 `MEISTER`)로 동작합니다.
> URL을 넣는 순간부터 시트의 개별 코드만 통과됩니다.

## 운영 방법

### 초대 코드 발급
"초대코드" 시트에 행을 추가하면 즉시 사용 가능:

| 코드 | 고객명 | 상태 | 만료일 | 사용횟수 | 마지막 사용 |
|---|---|---|---|---|---|
| `KIM-2026-A7` | 김○연 | 활성 | 2026-12-31 | (자동) | (자동) |

- **코드**: 자유 형식 (대소문자 구분 없음)
- **상태**: `활성` 만 통과. `중지` 로 바꾸면 즉시 차단
- **만료일**: 비워두면 무기한. 날짜가 지나면 자동 거부
- **사용횟수/마지막 사용**: 고객이 입장할 때마다 자동 기록 — 누가 실제로 들어왔는지 확인 가능

### 예약 수신
- 예약이 들어오면 "예약" 시트에 한 줄 추가 + **이메일 즉시 발송** (기본: 내 지메일)
- 알림 주소를 바꾸려면 `Code.gs` 맨 위 `NOTIFY_EMAIL = "원하는@주소"` 수정

### 코드를 수정했을 때
Apps Script 코드를 고친 뒤에는 `배포 → 배포 관리 → 수정(✏️) → 새 버전 → 배포` 를 해야 반영됩니다. (URL은 그대로 유지됨)
